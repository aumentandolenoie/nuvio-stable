# Nuvio Stable

Fork personalizzata basata sul client nativo GPLv3 **[Nuvio Native Legacy](https://github.com/iqui27/nuvio-native-legacy)**.

Questo repository viene inizializzato tramite una procedura di importazione della sorgente upstream, con modifiche mirate:
- le impostazioni compatibili con Nuvio ufficiale rimangono collegate al profilo e le opzioni specifiche del client nativo rimangono locali;
- la preferenza per i metadati forniti dagli addon esterni è facilmente accessibile;
- con «Scegliere la fonte alla riproduzione» attivo, il selettore si apre ad ogni avvio di film o episodio, anche da «Continua a guardare», senza interferire con la TV in diretta.

Il codice importato conserva la licenza e le attribuzioni originali. **Questa è una fork non ufficiale** e non è affiliata a NuvioMedia.

La procedura di importazione è descritta in `.nuvio-stable/README.md`.
